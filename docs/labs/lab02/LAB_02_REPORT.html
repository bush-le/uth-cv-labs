2b. Ghi Chú Phương Pháp: Chọn Ngưỡng T

YC4 — Vì sao chọn T = 80 / 127 / 180?

  • 127 là trung điểm của dải cường độ [0, 255] — mốc "trung tính" để tham chiếu.
  • 80 và 180 lệch ±50 quanh trung điểm, đại diện ngưỡng thấp và cao.
  • Đây chỉ là 3 mốc minh hoạ xu hướng; đề bài chỉ yêu cầu "thử nhiều giá trị T".

3. Quy Tắc Tổng Hệ Số Kernel

Trên một vùng ảnh phẳng (mọi pixel = c), tích chập cho output = c × (tổng hệ số kernel).

Tổng kernelÝ nghĩaOutput (c=100)Kỳ vọng
0.5Giảm độ sáng / scale5050
1.0Bảo toàn độ sáng100100
2.0Tăng độ sáng200200
0.0Xoá vùng phẳng, chỉ giữ biên00
Lưu ý quan trọng: tổng kernel bằng 1 chỉ đảm bảo bảo toàn độ sáng, không tự động nghĩa là làm nét. Mean và Gaussian cũng có tổng 1 nhưng làm mờ. Điều kiện để kernel thực sự làm nét: tổng = 1 VÀ có hệ số âm.

4. Phát Hiện Biên: Sobel vs Prewitt

Đạo hàm bậc 1 theo hai phương, kernel tổng = 0 nên triệt tiêu vùng phẳng và chỉ giữ lại biên.

Sobel X          Prewitt X
[-1  0  1]       [-1  0  1]
[-2  0  2]       [-1  0  1]
[-1  0  1]       [-1  0  1]
  tổng = 0         tổng = 0
  • Vì sao kết quả gần như giống nhau? Hai kernel chỉ khác duy nhất ở trọng số hàng giữa (2 so với 1); các hàng còn lại y hệt.
  • Cấu trúc biên trùng khớp: tương quan giữa Sobel|G| và Prewitt|G| đo được ≈ 0.996.
  • Khác biệt chủ yếu là biên độ: Sobel nhấn hàng giữa nên biên độ trung bình lớn hơn (≈ 39.5 so với ≈ 28.9, tức ~1.37×).
  • Sobel nhấn trọng số hàng giữa → làm mịt nhẹ theo phương vuông góc → ít nhạy nhiễu hơn; Prewitt hệ số đều 1 → đơn giản và tính nhanh hơn.
  • Độ lớn gradient: |G| = √(Gx² + Gy²) (dùng cv2.magnitude), hiển thị đã chuẩn hoá percentile 99 để không bị tối đen.
Laplacian [0 1 0; 1 -4 1; 0 1 0] có tổng = 0 là bộ phát hiện biên (đạo hàm bậc 2), KHÔNG phải bộ làm nét. Muốn làm nét từ Laplacian: lấy Ảnh gốc − Laplacian, vì Identity (tổng 1) − Laplacian (tổng 0) = tổng 1.

7. Tài Liệu Tham Khảo (References & Technical Documentation)

7.1. Thư viện Cốt lõi & Tài liệu API Chính thức

  1. OpenCV Image Filtering — cv2.filter2D, cv2.blur, cv2.GaussianBlur, cv2.medianBlur, cv2.bilateralFilter, cv2.Sobel, cv2.Laplacian.
  2. NumPy Broadcasting & Vectorization — tính toán điểm ảnh vector hoá.
  3. Matplotlib Pyplot API — hiển thị lưới ảnh và histogram.

7.2. Tiêu chuẩn Kỹ thuật & Giải thuật Nền tảng

  1. Gaussian Smoothing — kernel tách được (separable) thành tích hai vector 1D.
  2. Sobel & Prewitt Operators — xấp xỉ đạo hàm bậc 1, nền tảng của Canny / Harris.
  3. Laplacian Operator — xấp xỉ đạo hàm bậc 2, tổng kernel = 0.

7.3. Quy ước Thị giác Máy tính & Định dạng Dữ liệu

  1. Kernel Sum Convention — tổng hệ số quyết định hành vi: 0 (biên), 1 (bảo toàn độ sáng).
  2. OpenCV BGR Legacy Layout — ảnh mặc định BGR, đổi sang RGB để hiển thị đúng.
